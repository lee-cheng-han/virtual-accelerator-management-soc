# Compatibility matrix

The machine-readable matrix is [`tools/compatibility.json`](../tools/compatibility.json).
Release 1 supports hardware-interface major 1, firmware major 1, descriptor
major 1, and Linux UAPI 1 on the pinned QEMU and Zephyr revisions in
`tools/versions.env`.

An unsupported descriptor major produces a normal error completion without
payload DMA. The Linux driver refuses an unsupported hardware-interface major,
and an ioctl with an unsupported UAPI version returns `EINVAL`. Unknown minor
capabilities are ignored unless the command explicitly requires one. Commands
are never replayed automatically across a reset with uncertain compatibility.

CI verifies generated byte layouts, version rejection, the QEMU patch series
against its exact source commit, and current/current command behavior. Older
firmware/newer-host and newer-firmware/older-host artifacts will be added when a
second released interface revision exists; inventing those combinations before
then would not provide meaningful compatibility evidence.
